# Anurag Jaiswal - Personal Portfolio Website

A modern, responsive personal developer portfolio website designed for **Anurag Jaiswal**, first-year B.Tech Computer Science & Engineering student at **Bennett University**.

---

## 🌟 Features & Highlights

- **Dark Modern Aesthetic**: Charcoal/black surfaces (`#080c14`), glassmorphism cards, and emerald/teal/cyan neon glow accents.
- **Modern Typography**: Google Fonts (`Space Grotesk`, `Outfit`, and `JetBrains Mono`).
- **Interactive Developer Terminal**: Live tab switching (`anurag.py`, `terminal`, `profile.json`), copy code snippet button with toast feedback.
- **Authentic & Honest Technical Profile**:
  - Transparent skill levels (*Beginner/Intermediate*, *Basic*, *Learning*, *Active*) with no fake percentages or progress bars.
  - Active learning roadmap with a structured methodology (*Learn → Practice → Experiment → Improve*).
  - Highlighting exploration in AI-assisted development and vibe coding.
- **Interactive Timeline**: Visual milestone tracker for Anurag's college journey that can easily be updated each semester.
- **Fully Responsive**: Optimized for ultra-wide desktop, laptops, tablets, and smartphones with a mobile hamburger navigation drawer.
- **Zero Heavy Dependencies**: Pure **HTML5 + Vanilla CSS3 + Vanilla JavaScript** for instant load times and 100% offline reliability.

## 🚀 How to Run Locally

You can view the portfolio in any web browser:

### Option 1: Direct File
Double-click `index.html` in your file explorer to open it in Chrome, Edge, Brave, or Firefox.

### Option 2: Local Python Server (Recommended)
Open your terminal in this folder and run:
```bash
python -m http.server 8080
```
Then open [http://localhost:8080](http://localhost:8080) in your browser.

## 🌐 How to Host for Free

### Method 1: GitHub Pages (Easiest)
1. Create a GitHub repository named `portfolio` or `anurag-jaiswal.github.io`.
2. Push all the files (`index.html`, `style.css`, `script.js`, `README.md`) to the repository.
3. Go to **Settings** > **Pages** > Select `main` branch > Click **Save**.
4. Your portfolio will be live at `https://<your-username>.github.io/`!

### Method 2: Vercel / Netlify
1. Drag and drop the `Portfolio` folder into [vercel.com](https://vercel.com) or [netlify.com](https://netlify.com).
2. It will deploy automatically within 5 seconds with a custom HTTPS URL.
